## Issues and questions

- **Bugs and feature requests:** [GitHub Issues](https://github.com/vantagecompute/jupyterhub-theme/issues)
- **Notebook image problems:** [vdeployer issues](https://github.com/vantagecompute/vdeployer/issues)

When you report a problem, include the output of `jupyter labextension list`, the
JupyterLab version and, for a build failure, the full `pip install` output.
